# Home-Lab-v2
Homelab - IT and security home lab
A virtualized network, built to practice and demonstrate hands-on knowledge in IT and cybersecurity concepts. Everything is ran on a single laptop 16 gb ram, each phase is documented and include screenshots, problems I ran into, and how I solved those issues.

# Goal - Build and manage a realistic enterprise environment. Eventually this home lab will include monitoring, hardening, and attacking the managed environment.

# Environment
VMware Workstation Pro | Hypervisor
OPNsense | Firewall / router, network segmentation
Windows Server 2022 | Active Directory, DNS, DHCP, file server
Windows 10 Enterprise | Domain-joined workstation
Wazuh | SIEM
Kali Linux | Attacker
